# Dwelve RU — лендинг для российского рынка

Самостоятельный сайт для домена **dwelve.ru**. Живёт внутри репозитория `e:\Dwelve`,
но **не является подразделом канадского сайта**: у него свой `index.html`, свои цифры,
свой отчёт и свой кейс. Канадская версия в корне репозитория не трогается.

```
e:\Dwelve\
├── index.html            ← dwelve.ca  (не редактируется задачами RU)
├── sample-report.html    ← dwelve.ca
├── case-study.html       ← dwelve.ca
├── data/figures.json     ← цифры канадского отчёта
├── tools/                ← общие сборочные скрипты
└── ru/                   ← ЭТОТ ПРОЕКТ → dwelve.ru
    ├── index.html
    ├── data/figures.json ← свои цифры, независимо от канадских
    ├── assets/           ← PDF отчёта и кейса
    ├── photos/           ← копия фото (общий человек, разные сайты)
    ├── robots.txt
    └── sitemap.xml
```

## Деплой

Папка `ru/` заливается **как корень** домена dwelve.ru. Все внутренние ссылки —
относительные (`documents.html`, `photos/…`, `theme.css`), без ведущего слэша: так сайт
одинаково работает и в корне домена, и в подпапке предпросмотра на GitHub Pages. При
сборке бандла канадского сайта папку `ru/` нужно исключать — иначе один и тот же лендинг
окажется доступен и по `dwelve.ca/ru/`, и по `dwelve.ru/`, что размывает индексацию.

### Предпросмотр

Папка `ru/` — сама себе git-репозиторий (`youloseman/dwelve-ru-preview`), опубликованный
через GitHub Pages. Копии для деплоя, как `_share/` у канадской версии, здесь не нужно:
в `ru/` и так лежит ровно то, что уходит в продакшн, — ни `node_modules`, ни `tools/`.
Обновить предпросмотр — закоммитить и запушить из `ru/`.

Канонический адрес в `<head>` указывает на `https://dwelve.ru/`, а не на github.io: это
верно для продакшна и подсказывает поисковикам, что предпросмотр — не оригинал. Когда
домен заработает, предпросмотр стоит закрыть `noindex` или удалить.

## Что отличается от канадской версии

| | dwelve.ca | dwelve.ru |
|---|---|---|
| Тарифы | 4 уровня, CA$249 – CA$3 949 | 3 уровня: 50 000 / 197 000 / 84 000 ₽ |
| Структура лендинга | 16 секций | 5 блоков + футер |
| Юрисдикция | PIPEDA, privacy + terms | договор по законодательству РФ: оферта, 152-ФЗ, условия возврата |
| Отчёт | демо-кофейня, Виктория, BC | свой демо-бизнес, свои цифры |
| Кейс | `case-study.html` (2 страницы) | свой |
| Шрифты | Playfair Display + DM Sans + DM Mono | Playfair Display + Manrope + JetBrains Mono |

**Про шрифты:** DM Sans и DM Mono не содержат кириллицы, поэтому body и mono заменены.
Playfair Display кириллицу поддерживает и остаётся общим для обеих версий — это то, что
визуально держит два сайта одним брендом.

## Что не готово

Лендинг собран целиком, но три вещи ждут материалов и помечены в разметке классом
`.todo` — он подсвечивает плейсхолдер оранжевым пунктиром, чтобы такой хвост не уехал
в продакшн незамеченным.

| Что | Где | Состояние |
|---|---|---|
| Обработчик формы | `FORM_ENDPOINT` в конце `index.html` | Пусто. Пока адрес не задан, форма собирает письмо и открывает почтовый клиент |
| Ссылки на соцсети | Блок 4 и футер | `href="#"` |
| Реквизиты | Футер | «ИП / ООО, ИНН — уточняются» |
| Оферта, политика 152-ФЗ, условия возврата | `documents.html` | Страница-заглушка со статусом «готовится» |
| OG-картинка | `<head>`, теги закомментированы | Русский вариант ещё не отрисован |
| Пример отчёта | Ссылка в тарифе «Карта роста» | Ведёт на форму с предвыбранным «Пример отчёта» |

**Обработчик формы выбирать под российскую аудиторию.** Formspree, Getform и подобные
зарубежные сервисы у части посетителей не открываются без VPN — а форма на сайте вместо
ссылки на Telegram появилась ровно по этой причине. Подходят обработчик на самом хостинге,
Яндекс Формы или функция у российского облачного провайдера.

**Форму нельзя запускать в бой, пока не опубликована политика обработки персональных
данных:** чекбокс согласия ссылается на `documents.html#privacy`, и до появления текста
согласие не на что ссылаться.

## Цифры

Как и на канадской стороне, все несущие числа отчёта и кейса живут в `ru/data/figures.json`,
а не в HTML напрямую. Причина та же: одно число дублируется в двух документах, правишь одно —
второе молча расходится. Проверка соотношений появится вместе с отчётом.
